## Featured Projects

### [TradeCRM](https://github.com/sultonzoda2011/trade-crm-frontend) · [Backend](https://github.com/sultonzoda2011/trade-crm-backend)
A CRM for markets and shops that brings sales, customer debts, inventory, transactions, and analytics into one system. Includes role-based access, partial payments and refunds, a React frontend, a NestJS API, PostgreSQL, and an Android app built with Capacitor.

### [ClassView](https://github.com/sultonzoda2011/classview) · [Backend](https://github.com/sultonzoda2011/classview-backend)
A platform for educational centers to manage centers, classrooms, staff, and parents. Built with React, TypeScript, NestJS, Prisma, and PostgreSQL, with role-based access, multilingual UI, and HLS video streaming.

### [Pixel Runner](https://github.com/sultonzoda2011/pixel-runner)
