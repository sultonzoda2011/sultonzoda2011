## About

I'm a full-stack developer from Tajikistan building end-to-end web applications and product features. I work across frontend architecture, backend APIs, database design, authentication and authorization, analytics, and deployment.

I care about maintainable code, thoughtful user experience, and solving concrete problems with software.

## Core Stack

- **Frontend:** React, TypeScript, React Router, Redux Toolkit, TanStack Query, Zustand, Tailwind CSS, shadcn/ui
- **Backend:** Node.js, NestJS, REST APIs, Prisma, authentication, role-based access control
- **Data:** PostgreSQL, relational data modeling, migrations
- **Quality & Delivery:** Git, GitHub Actions, Playwright, automated checks, Capacitor for Android

## Featured Projects

### [TradeCRM](https://github.com/sultonzoda2011/trade-crm-frontend) · [Backend](https://github.com/sultonzoda2011/trade-crm-backend)
A CRM for markets and shops that brings sales, customer debts, inventory, transactions, and analytics into one system. Includes role-based access, partial payments and refunds, a React frontend, a NestJS API, PostgreSQL, and an Android app built with Capacitor.
